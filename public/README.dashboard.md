# Brian Control Center UI

Temporary mobile-first dashboard/PWA shell for Monster Coins Pro / Brian Market OS.

- Dashboard: `public/monster.html`
- Manifest: `public/manifest.webmanifest`
- Service worker: `public/sw.js`
- Runtime adapter: `dashboard_server.py`

The UI is SHADOW-only and deliberately keeps live execution locked. Vercel/Supabase wiring is a follow-up.
