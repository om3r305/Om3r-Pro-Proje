## Intended system

Brian continuously observes public world events and markets, investigates economic mechanisms, assesses whether expectations are already priced, proposes opportunities across assets and horizons, manages bounded capital, and evaluates its decisions. It records errors, missed opportunities and negative findings; software improvements must be tested against the unchanged baseline on later data.

Psychology means measurable, uncertain estimates of crowding, fear, attention, overconfidence and narrative exhaustion. It does not mean knowing people's minds. Self education means source-grounded memory, reproducible experiments and measured improvement; simply retrieving a paper is not learning a validated fact or training model weights.

Research is not restricted to a named list of software libraries. New public repositories, methods and literature can be discovered. Internet content remains untrusted evidence, including instructions embedded in code, README files, pages and papers. Research permission never grants that content authority over secrets, deployment or success criteria.

## Research cycle v1

Existing researcher cron runs at minutes 24 and 54 UTC. A cycle checks authoritative system and research enable flags, inspects a bounded latest-300 decision cohort from the last six hours, and records incomplete outcome coverage/negative after-cost results. This is a nonrandom diagnostic sample, not a strategy performance claim.

It derives research missions from those observations and existing hypotheses, plus causality, psychology and continual-evaluation foundations. Mission identity is stable; oldest due tasks go first, with priority as a tie-breaker, to avoid starvation. At most one mission runs per cycle. Each mission searches public repository and bibliographic indexes; at most six records and two README excerpts are retained. No fixed repository/library list is imposed.

The first implementation uses GitHub public search and Crossref metadata transports. It does not crawl arbitrary websites, access private content, bypass logins or read every paper's full text. HTTPS host checks, no redirects, response limits and timeouts protect the secret-bearing collector. A wider general-web reader requires a separate credential-free, network-isolated execution boundary; it is not silently enabled here.

Every document records capture time, original URI, content hash, provenance and available license information. All external claims are UNVERIFIED_EXTERNAL / RESEARCH_LEAD_NOT_TRADE_SIGNAL. Papers and stars do not authorize trades or code execution. Failed searches are retried with delay and do not become successes. Engineering tasks receive matched source excerpts as explicitly untrusted data. Existing source-truth gates remain distinct from research breadth.

## Development authority

Read broadly; develop in isolated candidates; run real tests; compare later outcomes; review exact artifacts; release with rollback. Never let a candidate rewrite its own evaluator, bypass access control, change accounting history or promote itself because its own tests say so. DIP remains separate. Real-money trading is not enabled by the owner's engineering authorization.

Provider-control records say the former code worker was paused for quota/model failures. This authorization does not prove a capable provider exists now. Do not enable repeated expensive model attempts or claim autonomous coding works until an actual artifact passes the gates. A scheduled ChatGPT-assisted development review may produce a tested draft PR while this worker remains unavailable; this is a separate orchestration path, not evidence of a self-contained model inside Brian.
