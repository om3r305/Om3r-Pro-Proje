Scope: product data flow only. No engineering queue, software-intake timer, model provider, strategy threshold or real-money changes. Base 58d3a7ff285d1fe62ecdebac07a2f057e2b81eed.

A new CORE collector watches valid-reference shadow ALPHA decisions over the next 5/15/60 minute windows, including WAIT/VETO, independently of radar or action strength. One public bulk bookTicker request per minute; at most 500 watched assets, bounded bytes/time, explicit capacity/invalid/missing-quote errors and provider cooldown. It starts alongside the existing Realtime market lane, not after a successful radar/kline run. No new cron job or engineering schedule is introduced.

The existing append-only audit price path accepts a separately identified CORE source as well as its original REALTIME records. New fields preserve bid/ask decimals, request start, receipt observation and database capture time. The provider has no exchange timestamp here: HTTP_RECEIPT_TIME_EXCHANGE_TIME_UNKNOWN is explicit. Midpoint is computed with PostgreSQL numeric arithmetic; no quote or exchange-time fabrication. New price-only receipts have unknown cost (null), never inferred zero transaction cost. One deterministic event per asset/minute makes retries idempotent.

The existing auditor, pending queue and live outcome coverage query already read this audit table without restricting it to REALTIME. No new public browser access is granted. RPCs are SECURITY INVOKER, service_role-only; RLS and the original append-only trigger remain. The operator STOP flag is checked before network work, before persistence and again inside the persistence transaction. No changes to the stop flag itself.

The 19 October fixed coverage cohort remains unchanged. Capture starts during that cohort, so any before/after difference is observational and not a controlled causal comparison. Missing historical ticks are not backfilled, terminal tolerance stays +120s, and sparse path samples still understate possible between-sample excursions. This improves measurement coverage; it does not establish trading profitability or full source freshness.
