# Source-driven atmosphere — isolated preview

Fullscreen verified on 5120 × 1440 display at 125% scaling (4096 × 1152 CSS).
Drawing buffer: 6108 × 1374, render ratio 2; ULTRA budget 12 million pixels.
Actual 15-second benchmark: 60.0355 rendered FPS, p95 16.9 ms, mean JS 2.084 ms, GPU draw 1.137 ms. GPU buffer estimate 132.1 MiB is a lower bound, not total process memory.

Main theme remains black/silver. Electron modules retain their own color. Brighter local coronas and packet sprites emphasize incoming/outgoing decorative carriers. The core changes color with validated source state. A visible badge gives the reason and JSON path.

- White: normal observation, no qualifying warning/opportunity field.
- Gray: missing/stale/transport-degraded source; no positive classification.
- Muted green: current OPEN_LONG/OPEN_SHORT **shadow candidate**, not proven advantage.
- Bright green: opening candidate AND explicit alpha.opportunity_strength = STRONG. Without that field the strong effect cannot fire. No evidence-score threshold or profitability inference is invented.
- Yellow: explicit WARNING/HIGH severity or current VETO/BLOCKED action.
- Red: explicit CRITICAL/EMERGENCY severity or recent failed module (labeled system fault, not market crisis).
- Replay: separate recorded-data state, never presented as current market activity.

Source membership edges are not real packet transport. Continuous waves/electrons are decorative; changed source timestamps trigger the existing record notification pulse. The current public envelope does not guarantee individual news impact/severity fields; unprovided events cannot drive market-critical atmosphere. No synthetic event is injected into the live preview.

Six classifier tests passed, including stale/replay suppression and strong-opportunity gating. Browser showed no WebGL errors and no page overflow. Adaptive render scaling, pause, and reduced-motion behavior remain in effect. Production BRIAN, experiments and order execution remain untouched.
