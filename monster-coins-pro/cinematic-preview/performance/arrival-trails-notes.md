# Preferred artwork with coordinated arrival effects

The user reviewed the new physical sphere rendering and preferred the earlier module artwork. The physical module bodies, sprite logos and 3D electron orbits were therefore removed before delivery. The preferred luminous CSS module balls and existing WebGL core remain in place. Do not describe this version as having fully 3D module artwork.

Retained enhancements:
- Nine GPU trail samples per continuous carrier, with fading wakes (decorative).
- Changed current-source timestamps trigger a 2.8-second visual record journey.
- At the end of that journey, three expanding 3D rings and a core shader ripple appear.
- Source module pulses at dispatch; core and module coronas react at arrival; panel edge accents respond to the same impact clock.
- The whole animation uses the pause-aware scene clock. No source change, stale source or replay produces a new arrival impact.

Fullscreen measurement: 60.024 FPS over 15 seconds; 6108 × 1374 drawing buffer; mean JS 2.222 ms, GPU draw 1.324 ms; p95 16.9 ms. No production deployment or experiment was performed. Source data remains read-only.
